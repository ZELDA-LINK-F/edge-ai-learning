## 一、这套东西是什么

| 项 | 内容 |
|---|---|
| 定位 | 在 8GB 边缘设备上，**不靠现成框架**手搭一个 AI 助手 |
| 核心信念 | **能力在系统里，不在模型里** —— 1.5B 小模型 + 路由/检索/工具/兜底，效果远超它的体量 |
| 形态 | **纯终端**（前人的"用户"明确否决了网页界面） |
| 人设 | 「团子」——住在 Jetson 上的小家伙 |
| 现状 | 对话✅ 问答✅ RAG✅ 工具✅ 视觉✅ **ASR✅** ｜ TTS⚠️（能出声但音色僵硬） |

**两个命令（已装进 `~/.local/bin`，任何目录可用）：**
```bash

```

## 二、架构：一条决策链（最重要的图）

一次提问会这样流动（`总纲.md §3`）：

```
用户提问
  ↓
⓪ 记忆意图识别（代码兜底，不经过模型）      ← 挡住"假承诺"
  ↓
② 判难度（语义路由：bge 向量 + kNN，常驻服务 :11500）
   ├── 简单/闲聊 → ④ 本地模型（免费、快）
   └── 复杂     → ③ 先查自己笔记（RAG）→ 不够再走云端 API
  ↓
④ 生成（本地 qwen-fast 或 云端）
  ↓
只输出答案（内部细节默认隐藏，-v / /debug 才显示）
```

**三条铁律（前人用血换的）：**
1. **RAG 只认资料** —— 给它的 system 里不塞记忆、不塞人设，否则它会"拿自己的知识编答案还标着 📚 RAG"（等于骗用户）
2. **能靠代码兜的，绝不交给 1.5B** —— 它做不到的事（认"你/我"、判断是否要记忆），写代码
3. **对用户说话的每一步才装人设**，做决定的那几步不装

## 四、9 篇笔记 = 9 堂课（这就是你的教材）

| 笔记 | 讲什么 | 最有价值的一句 |
|---|---|---|
| **02 结构化输出** | 让模型吐 JSON | **模型输出的是「文本」不是「数据」**；工程能兜格式，兜不住语义 |
| **03 视觉** | 加眼睛（VLM） | 视觉比文本"重"得多（3B 文本 3.2G vs 视觉 5.8G）；**内存 = 权重 + ViT + KV缓存** |
| **04 难度判别器** | 72% → 90% → 98% | 关键词法的天花板是 90%；**语义路由靠"参考句 + kNN"，不靠规则** |
| **05 RAG** | 查资料 | RAG ≠ 微调；**markdown 符号会污染向量**（存原文、洗嵌入） |
| **06 工具调用** | 让模型动手 | **模型只负责"决定用哪个工具"，执行永远靠你的代码** |
| **07 根因修复** | 崩溃 + 误判 | **修 bug 第一步是造稳定复现器**，不是改代码 |
| **08 人设与记忆** | 把不可靠的活拿走 | **token 可以直接量**（0.87 token/汉字）；对 1.5B 写"不要 X"会招来 X |
| **09 语音识别** | 加耳朵 | 识别本身 0.21s（比实时快 20 倍），**慢的全是进程启动税（15s）→ 常驻 daemon** |
| **10 语音输出** | 加嘴巴 | Kokoro 僵硬是**架构问题**（非自回归），换 55 个音色也没用 |

## 五、29 条坑 → 你的避坑地图

| 主题 | 坑号 | 一句话 |
|---|---|---|
| **模型行为** | 10,11,19,20,24,28 | 小模型会编造、会做**假承诺**、会分不清"你/我"；"不要 X"反而抬高 X 的概率 |
| **工程兜底** | 3,13,14,18,22,23,25 | 先造复现器；持久化会把旧逻辑变成 bug；纯指代短句（"就它了"）没有语义、检索必错 |
| **RAG/语料** | 5,6,7,26,27,29 | **把问题记进笔记，问题就变成了正例**；大块资料会挤垮检索（一份规格书占 61% 语料） |
| **资源实测** | 1,4,15,17 | **资源必须实测**（估 0.5GB 实测 1.8GB）；量化不是崩溃的变量；token 可以量 |
| **提示词** | 2,8,9,16,21 | 让模型做选择**必须给示例**；改动要**做对照实验**定位是哪一处起作用 |

> 原文在 `总纲.md §7`，每条都有实测证据。**通读一遍 = 省下一个月的试错。**

## 六、我发现的问题（前人留下的坑 / 需要注意）

| # | 问题 | 说明 |
|---|---|---|
| 1 | **RAG 会答过期数字** | 问"语义路由准确率"，它答 98%（真实 100%）——因为另一篇笔记也写了 98%，把正确答案挤掉了。**这就是"语料即真理"的活教材** |
| 2 | **`.env` 里有前人的云端 API key** | `API_KEY / API_BASE / API_MODEL`（deepseek）。⚠️ **继续用等于花别人的钱**，建议换成你自己的 |
| 3 | **`记忆.md` 存的是前任用户的私人事实** | 内容属于前一位使用者（笔记里称"小周"）。你可以自己打开看/清空 |
| 4 | **文档落后于磁盘** | `总纲.md §8` 写"ASR ⬜ 未完成"，但磁盘上 `asr-server` 早已跑起来（笔记 09/10 是后来补的）。**前人自己也提醒过：先看文件再看记忆** |
| 5 | **ASR 常驻吃 1.7~4.3GB** | 我已经临时停掉（否则本地模型会 CUDA OOM）。这就是前人笔记 10 说的"内存墙" |
